## 1. Описание базового приложения

В рамках лабораторной работы было создано простое мобильное приложение «Приветствие» на платформе Kodular. Приложение позволяет пользователю ввести свое имя и получить персонализированное приветствие. В дизайне использована цветовая гамма «Golden Brown» (золотисто-коричневые тона). На первом экране (Screen1) обязательно размещена фамилия студента на английском языке (Mikhed).

**Реализованные дополнительные возможности (ачивки):**
1. **Ачивка 6: Генератор QR-кода** — с помощью компонента `QR_Code` создается QR-код с введенным именем, который затем отображается в компоненте `Image`.

## 3. Использованные AI-промпты

В ходе работы использовались следующие ключевые промпты для нейросети:
1. *«Как в Kodular сделать так, чтобы при нажатии на кнопку проверялось, пустое ли текстовое поле, и выводилось сообщение?»* — для построения базовой логики if/then.
2. *«Почему в Kodular блок if/then/else не принимает команды set внутри себя и как это обойти?»* — для решения проблемы с логикой ветвления.
3. *«Как сгенерировать QR-код из текста в Kodular и показать его на экране?»* — для реализации Ачивки 6.

## 4. Освоенные компоненты и блоки

**Компоненты (Designer):**
* `Label` (для заголовков и вывода результата)
* `TextBox` (для ввода имени)
* `Button` (для запуска действия)
* `Image` (для отображения QR-кода)
* `QR_Code` (невидимый компонент для генерации QR-кода)

**Блоки (Blocks):**
* `when Button1.Click do` (событие нажатия)
* `if / then` (условные конструкции)
* `not` (логическое отрицание)
* `=`, `""` (сравнение и пустая строка)
* `join` (склейка текста)
* `set Label.Text to` (изменение текста)
* `call QR_Code.GenerateQrCode` / `when QR_Code.GotResponse` (генерация и получение картинки)

## 7. Выводы

В ходе выполнения лабораторной работы я освоила платформу Kodular для создания мобильных приложений без кода. Я научилась работать с визуальными компонентами (Label, TextBox, Button, Image), настраивать их свойства и создавать логику с помощью блоков (условия, склейка строк, работа с событиями). 

Особенно полезным было изучение работы с невидимыми компонентами: компонент `QR_Code` позволяет генерировать изображения на лету. Также я научилась тестировать приложение в реальном времени на телефоне через Kodular Companion. Платформа Kodular показалась мне мощным инструментом для быстрого прототипирования, который отлично подходит для создания простых утилит и учебных проектов.
